# Кейс 3. Автоматическая сборка и развёртывание приложения

## Цель
Настроить автоматический процесс сборки и развёртывания приложения с помощью GitHub Actions.

## Используемые инструменты
- GitHub
- GitHub Actions
- Python
- Pytest

## Этапы CI/CD
1. Запуск автоматического тестирования приложения.
2. Сборка приложения в ZIP-архив.
3. Сохранение архива как артефакта сборки.
4. Имитация развёртывания приложения.

## Особенности реализации
Вместо CircleCI и Heroku используется GitHub Actions.
Развёртывание выполняется в демонстрационном режиме без публикации приложения на внешнем сервере.
